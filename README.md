# موقع نور المجد لمواد البناء - الكويت 🚚🧱

موقع رسمي لمؤسسة **نور المجد لمواد البناء** في الكويت، يعرض تشكيلة شاملة من مواد البناء والإنشاءات مع توفير خدمة التوريد والنقل بواسطة **هاف لوري** إلى كافة مناطق وقسائم ومشاريع الكويت.

## 🌟 مميزات الموقع

- **كتالوج مواد بناء متكامل (17 مادة)**:
  - **قسم الطابوق**: طابوق أسود، طابوق أبيض عازل.
  - **قسم الصلبوخ والرمل**: صلبوخ أسود، صلبوخ أبيض، صلبوخ ورمل مغسول.
  - **قسم الأسمنت**: أسمنت أسود، أسمنت أبيض رأس الخيمة.
  - **قسم لاصق السيراميك**: صناعات وطنية، بسكونايت، الطنيب.
  - **قسم مستلزمات المساح والتشطيب والعزل**: شبك مساح، الزاوية والفواصل النهائية، معجون أكريليك GTC، الزفتة الأهلية (كابسيل).
  - **قسم الحديد ومواد التثبيت**: حديد تسليح، مسمار فولاذ، مسمار خشابي.
- **توافق كامل مع الهواتف الذكية (Mobile-First)**:
  - عرض شبكي مزدوج (عمودين) يناسب أبعاد شاشات الجوال.
  - زر تبديل طريقة العرض (شبكة 2 عمود / بطاقات 1 عمود).
  - شريط تنقل سفلي مثبت (Sticky Bottom Bar) للطلب عبر واتساب والاتصال السريع بنقرة واحدة.
  - شريط فلترة وتصنيفات أفقي قابل للتمرير باللمس.
- **تواصل وطلب سريع**:
  - اتصال هاتفي مباشر على: **55225082**
  - محادثة واتساب مجهزة برسالة تلقائية للمنتج المطلوب.
  - نموذج طلب ديناميكي يحول بيانات الطلب إلى محادثة واتساب جاهزة.
- **أعلى معايير الـ SEO وأرشفة Google**:
  - وسوم Schema.org JSON-LD لمواقع الأعمال المحلية (LocalBusiness).
  - وسوم Open Graph و Twitter Cards.
  - ملف `sitemap.xml` متكامل للصور والصفحة.
  - ملف `robots.txt`.
- **شعار فيكتور أصلي (Vector SVG Logo)**:
  - يحتوي على رسمة الهاف لوري محمل بالمواد واسم المؤسسة بخط عربي مميز.
